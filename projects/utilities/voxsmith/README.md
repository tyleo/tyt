# voxsmith

Operations over `voxcore` states. `operations` holds one module and feature per `vxl` command group. `utilities` holds palette reduction, dithering, color spaces, the material property ranges, and the object and node selectors. `dependencies` holds the traits the operations take from the caller: the PNG encoder the mesh bake and the render write through, and the voxelizer's image decoder. `DependenciesImpl`, behind the `impl` feature, binds them over `png` and `zune-jpeg`. The voxel file formats live in `voxconv` and the mesh file formats in `meshconv`. The mesher and the corner occlusion live in `voxsurface`.
