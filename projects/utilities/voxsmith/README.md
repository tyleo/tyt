# voxsmith

Operations over `voxcore` states. `operations` holds one module and feature per `vxl` command: the info, validate, hierarchy, and palette reports, meshing into a `meshdoc` document, voxelizing one, and the object pruning behind `to`. `utilities` holds palette reduction, dithering, color spaces, the material property ranges, and the object selectors. `dependencies` holds the traits the operations take from the caller: the mesh bake's PNG encoder and the voxelizer's image decoder. `DependenciesImpl`, behind the `impl` feature, binds them over `png` and `zune-jpeg`. The voxel file formats live in `voxconv` and the mesh file formats in `meshconv`.
