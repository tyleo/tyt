# voxsmith

Operations over `voxcore` states. `operations` holds one module and feature per `vxl` command group. `utilities` holds palette reduction, dithering, color spaces, the material property ranges, the object and node selectors, and the voxelizers' grid resolution, frame, fill mode, and flattening. `dependencies` holds the traits the operations take from the caller. `DependenciesImpl`, behind the `impl` feature, binds them. The voxel file formats live in `voxconv`, the mesh file formats in `meshconv`, and the SDF file formats in `sdfconv`. The mesher and the corner occlusion live in `voxsurface`.
