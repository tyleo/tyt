# vmax

Core types for the Voxel Max (`.vmax`) scene format: the on-disk data model for Voxel Max projects, covering the scene graph (objects, groups), voxel storage (per-chunk snapshots), materials, palettes, brushes, camera, and tool state. It also models the parts the format keeps alongside the live scene: the undo history (`*.vmaxhb` / `*.vmaxhvsb` / `*.vmaxhvsc`) as typed sessions and snapshots, and the `QuickLook/` thumbnails as decoded images. The history's undocumented per-command undo/redo payloads, whose shape varies per command, are held as faithful `VMaxValue` trees so they round-trip without being interpreted; saved selections (`*.selection.vmaxb`) are the one payload still kept as verbatim bytes. This crate is the Rust data model with optional `serde` support, defining the types for `.vmax` packages and their `.vmaxb` / `.vmaxpsb` payloads rather than the reading and writing of them.
