# vmax

Core types for the Voxel Max (`.vmax`) scene format: the on-disk data model for Voxel Max projects, covering the scene graph (objects, groups, snapshots), voxel storage, materials, palettes, brushes, camera, and tool state. The rest of the package is held verbatim so it round-trips without loss: undo history (`*.vmaxhb` / `*.vmaxhvsb` / `*.vmaxhvsc`), saved selections (`*.selection.vmaxb`), and `QuickLook/` thumbnails. This crate is the Rust data model with optional `serde` support, defining the types for `.vmax` packages and their `.vmaxb` / `.vmaxpsb` payloads rather than the reading and writing of them.
