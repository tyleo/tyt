# vmax

Core types for the Voxel Max (`.vmax`) scene format: the on-disk data model for Voxel Max projects, covering the scene graph (objects, groups, snapshots), voxel storage, materials, palettes, brushes, camera, and tool state, plus the rest of the package — undo history (`*.vmaxhb` / `*.vmaxhvsb` / `*.vmaxhvsc`), saved selections (`*.selection.vmaxb`), and `QuickLook/` thumbnails — held verbatim so a package round-trips without losing them. This crate is the Rust data model with optional `serde` support; reading and writing `.vmax` packages and their `.vmaxb` / `.vmaxpsb` payloads lives in the companion `vmax-codec` crate.
